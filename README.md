# Análise de Dados com AWS Athena

## 📌 Descrição
Projeto desenvolvido durante o curso **Profissão Analista de Dados v2 (EBAC)**,
utilizando **AWS S3** e **AWS Athena** para análise de dados em nuvem.

O objetivo foi realizar consultas SQL aplicando funções de agregação
como `COUNT`, `GROUP BY`, `MIN`, `MAX`, `AVG` e `HAVING`.

---

## 🧰 Tecnologias Utilizadas
- AWS S3
- AWS Athena
- SQL
- Google Colab

---

## 📊 Dataset
- Dataset de doenças cardíacas (`heart_disease_dataset_completo.csv`)
- Armazenado em bucket S3
